# Public Website Rebuild Scope Planner

A browser-private Evolved Designs tool for turning website, portal, and web-app requirements into a phased, acceptance-ready scope. It now includes an explicit search-discovery handoff covering indexability, crawlable links, sitemap state, and post-launch evidence.

The standalone deployment is retired. Use Evolved Designs' maintained native [Website Procurement Readiness](https://evolveddesigns.net/website-procurement-readiness/); this repository preserves the earlier browser-private source.
